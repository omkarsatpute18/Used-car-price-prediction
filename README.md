# 🚗 Used Car Price Prediction

A machine learning web application that predicts the estimated resale price of a used car based on its details.

## 🌐 Live Demo

**[CarValue – Used Car Price Prediction](https://used-car-price-prediction-alpha.vercel.app/)**

## 🛠️ Tech Stack

- Python
- Flask
- Scikit-learn
- Random Forest Regression
- HTML, CSS & JavaScript
- Vercel

## 📊 Features

- Predicts used-car resale price
- Uses car brand, year, kilometers, fuel type, transmission, seller type, and ownership
- Simple and responsive web interface
- Instant price prediction

## ⚙️ How It Works

The model is trained on used-car listing data and uses **Random Forest Regression** to estimate the car's market value.

## 🚀 Run Locally

```bash
git clone <your-repository-url>
cd Used-Car-Price-Prediction
pip install -r requirements.txt
python app.py
```

Then open:

```text
http://127.0.0.1:5000
```

This project is created for **educational and portfolio purposes**. The predicted price is an estimate and may differ from the actual market price.
